1. Título y Descripción Genérica
  PROTECTORA DE ANIMALES.

  Nuestro trabajo se centra en el funcionamiento de una base de datos para una protectora de animales, Para realizarla hemos empleado distintas técnicas aprendidas a lo largo del curso de programación orientada a objetos(POO).

2. Arquitectura del Código (El punto fuerte)
  Explicación de los conceptos técnicos empleados:

  - Herencia: Perro y Gato heredan de Animal.

  - Herencia Múltiple: Contamos con una clase Voluntario, que es un usario que también realiza trabajos en refugio, contando también como trabajador.
    
  - Clase Abtracta: La clase Empleado, por ejemplo, usa la abtracción para indicar que todo empleado debe indicar su trabajo.
    
  - Clases públicas y privadas: La clase empleado cuenta con clases privadas, definiendo el dni cómo algo privado.

3. Características Principales
  El programa permite:

  - Registrar nuevos ingresos.

  - Gestión de los estados de adopción.

  - Asignación de cuidadores y dietas específicas.

4. Requisitos e Instalación
   
  - Lenguaje: Python

  - Comando para ejecutarlo: python main.py.
